# Relay releases

Builds of Relay, the native messenger for Android and macOS. Every release here is published
automatically, and installed copies of Relay update themselves from the latest one.

## Download

Open the [latest release](https://github.com/openformation/relay-releases/releases/latest):

- **Android:** `Relay-<version>.apk` (phones, arm64). `Relay-<version>-emulator.apk` is for x86_64 emulators.
- **macOS:** `Relay-<version>-macOS.dmg` (universal, Apple silicon and Intel, macOS 14 or later).

Each release lists SHA-256 checksums in `SHA256SUMS`.

## Updates

Relay checks for new versions on its own (about every 6 hours on Android and 4 hours on macOS).
When one is out, an **Update** button shows the release notes and installs it. Automatic
installs can be switched off in Relay's settings.

Pre-releases are for testing and are never installed automatically.
